Aktivitas 1: Dasar Console.log & Konsep Variabel

Mengenal output dasar dan peran variabel dalam pemrograman

Pertanyaan 1.1:

Apa fungsi dari perintah console.log() dalam JavaScript?

Jawaban: Perintah console.log() digunakan untuk menampilkan output, pesan, nilai variabel, atau informasi debugging ke dalam console browser atau terminal NodeJS.

Pertanyaan 1.2:

Mengapa kita membutuhkan Variabel dalam program JavaScript?

Jawaban: Variabel dibutuhkan sebagai wadah/tempat penyimpanan data sementara di memori komputer sehingga data tersebut dapat diakses, diubah, dan dipergunakan kembali di bagian kode lainnya selama program berjalan.

C

Catatan Penting: Aturan Penamaan Variabel (Naming Rules)

Standar baku penulisan variabel dalam JavaScript

  • Variabel bersifat Case-Sensitive (namaUser berbeda dengan namauser).
  • Karakter pertama tidak boleh berupa angka. Harus diawali huruf, underscore (_), atau simbol dolar ($).
  • Tidak boleh menggunakan reserved keywords JavaScript (seperti class, function, let, return, if).
  • Direkomendasikan menggunakan format camelCase untuk multi-kata (contoh: totalHargaBarang).

Aktivitas 2: Memperbaiki Pengubahan Nilai `const`

Analisis dan penanganan TypeError pada variabel konstan

// Kode Bermasalah (Error):

const pi = 3.14;

pi = 3.14159; // TypeError: Assignment to constant variable.

Solusi & Penjelasan Jawaban:

Jika nilai variabel pi perlu diubah di tengah eksekusi program, maka deklarasi harus diubah dari const menjadi let.

let pi = 3.14;
pi = 3.14159; // Berhasil tanpa error!

Aktivitas 6: Penggabungan String (String Concatenation vs Template Literals)

Teknik penyambungan variabel dan string

// Cara Lama (Concatenation):

Tugas Individu: Program Data Produk Sederhana

Lampiran sintaks dan penjelasan program JavaScript lengkap

// File: dataProduk.js

// Dibuat oleh: Izhad Ananda Risan (X PPLG 2)


const namaKategori = "Elektronik";

const namaProduk = "Mouse Gaming RGB";

const hargaSatuan = 250000;

let stokTersedia = 15;

let jumlahBeli = 2;


// Perhitungan Total

let totalBiaya = hargaSatuan * jumlahBeli;

stokTersedia -= jumlahBeli; // Mengurangi stok


console.log(`==== STRUK PEMBELIAN ====`);

console.log(`Kategori : ${namaKategori}`);

console.log(`Produk : ${namaProduk}`);

console.log(`Total Bayar : Rp ${totalBiaya.toLocaleString('id-ID')}`);

console.log(`Sisa Stok : ${stokTersedia} unit`);

Penjelasan Singkat Kode Program:

1. Menggunakan const untuk data konstan yang nilainya tidak berubah seperti nama kategori, nama produk, dan harga satuan.

2. Menggunakan let untuk stok dan jumlah beli karena nilainya akan berubah seiring transaksi berjalan.

3. Menggunakan template literals untuk pencetakan luaran yang rapi dan mudah dibaca.
